# CareerPrep AI
An AI-powered Resume Builder + Interview Coach with real-time camera, voice, and answer analysis.

## Features
-  Smart Resume Builder with AI suggestions
-  AI Interview Trainer with live Q&A feedback
-  Body language & eye contact analysis
-  Voice tone & filler word detection
-  Detailed interview score card

## Tech Stack
- Frontend: React.js + Tailwind CSS
- Backend: FastAPI (Python)
- AI: OpenAI API + LangChain + FAISS
- Speech: Whisper API
- Vision: MediaPipe
